# Artwork provenance

Widal Factory currently retains inherited Ovis artwork. The sleeping sheep, earlier ram, icons, screenshots and social previews are upstream assets, not a new Widal logo. Preserve their authorship and [third-party notices](../../THIRD_PARTY_NOTICES.md).

There is no shared Widal brand configuration on this documentation base. Product naming in prose does not implement application icons, native packaging, email sender or theme configuration. Those remain separate integration work.

The former artwork-generation and website-preview instructions remain in [Git history](https://github.com/Widal-Inc/factory-web-ui/blob/bb0d0f9b234e1c59b98e3ad01060b8d3dc4bd0e9/docs/brand/README.md). Do not republish upstream website branding as Widal artwork. Theme colors still change only in `src/styles.css` and flow through `bun run generate:themes`; generated copies must not be edited by hand.
