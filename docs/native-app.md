# Native-app status

The inherited Ovis desktop/mobile wrappers, store copy and native distribution workflow is retired as Widal Factory setup guidance. Do not use upstream accounts, pairing links, relay infrastructure, store listings or downloads to set up this fork.

Shared Widal sign-in, verified proxy identity, owner authorization and Setup are pending integration. Fork-owned packaging, signing, publication and update feeds also need implementation and validation before native releases can be offered. No replacement service or download URL is supplied here.

These docs do not claim that the inherited code has been removed from every build. Use the [local source workflow](../INSTALL.md) and its access boundary.

## Notifications

Inherited native push and web-push implementations do not establish a Widal notification service. The source workflow requires none of the former push-relay deployment steps.

## Historical provenance

The original upstream design, protocol and verification notes remain in [Git history](https://github.com/Widal-Inc/factory-web-ui/blob/bb0d0f9b234e1c59b98e3ad01060b8d3dc4bd0e9/docs/native-app.md). They describe historical upstream behavior, not a supported Widal service or security guarantee. Retained application identifiers and artwork are compatibility/provenance material, not a new Widal logo.
